SubtitleCat

Finds subtitles on subtitlecat.com by matching the release name of your media file. Enable it per library under Dashboard > Libraries > (your library) > Subtitle downloaders, otherwise it never gets asked for anything.

General

Turns the provider off without uninstalling it.
subtitlecat generates almost everything except the original language by machine. Turning this off leaves very few results.

Matching

Subtitles are timed to the cut, not the resolution, so the same group's 1080p subtitle normally fits a 2160p file exactly. Leave this on.
Higher is stricter. 40 is a title and year match.
Whether a language exists varies per release entry, so checking more of them finds more. Each one is a request.
When the release name finds nothing, retry with the title and year, or the series and episode number.

Translate on the fly

subtitlecat only stores a subtitle in a language once somebody has generated it. When yours is missing, the plugin can fetch the original and translate it here instead. That work happens when you pick the result, not while searching, and takes a minute or two for a film.

What subtitlecat stores is Google output. Leave this on if your backend does better, and you will see both entries and can pick.
